# License texts

This directory contains license texts used by gmesh itself or retained for
planned third-party dependency review.

| File | Applies to |
|---|---|
| `GPL-3.0-or-later.txt` | gmesh project code; GPL portions of a future CGAL integration |
| `GPL-2.0-or-later.txt` | Planned ADMesh integration, together with ADMesh's per-file “or later” notices |
| `LGPL-3.0-or-later.txt` | Any future CGAL files explicitly licensed under LGPL-3.0-or-later |

The `-or-later` permission is established by the applicable source-file notice,
not by changing the standard GNU license text. Keep the upstream notices with
all copied or modified third-party files.

Merely storing a license text here does not mean the corresponding dependency
has been integrated into a released binary.
