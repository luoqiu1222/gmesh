# License texts

This directory contains license texts used by gmesh and its build dependencies.

| File | Applies to |
|---|---|
| `AGPL-3.0-only.txt` | gmesh project code derived from OrcaSlicer |
| `BSL-1.0.txt` | Boost 1.84.0 and CGAL support files carrying the Boost Software License |
| `GPL-3.0-or-later.txt` | GPL-licensed CGAL packages used by repair |
| `GPL-2.0-or-later.txt` | ADMesh, together with its per-file “or later” notices |
| `LGPL-3.0-or-later.txt` | CGAL foundation/support files explicitly under LGPL-3.0-or-later |

The `-or-later` permission is established by the applicable source-file notice,
not by changing the standard GNU license text. Keep the upstream notices with
all copied or modified third-party files.

Dependency sources are fetched or supplied at build time and form part of the
complete corresponding source for a distributed binary.
